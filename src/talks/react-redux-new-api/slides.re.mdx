# useSelector

`useSelector(selector: Function, equalityFn?: Function);`

{/* まずは useSelector について説明します。その名の通り、特定のSelectorを使って、値を取ってくる Hooks です。 */}

---

#### useSelector

```jsx {5}
import React from "react";
import { useSelector } from "react-redux";

const Foo = ({ title }) => {
  const title = useSelector(state => state.title);

  return <button onClick={onPressBar}>{title}</button>;
};

export default Foo;
```

{/* 使い方としてはこんな感じです。 store の state を引数として、必要な値を取り出します。 selector の返り値がそのまま値として使えます。 今まで mapStateToProps として定義していた関数を useSelector に入れるイメージですね。 mapStateToProps と違って、Object を返す必要は無いので、単一の値が必要な場合はこの例にあるように、それをそのまま定義できます。 */}

---

## useSelector

- `mapStateToProps` の代わり
- selector の結果が変更されたら rerender される
- 複数の値を Object として取ってくる場合：

  - 第二引数に `shallowequal` を入れる
  - `reselect` を使う

{/* useSelector は今までのmapStateToPropsの代わりに使えます。 ただ、一つ注意点があります。 useSelectorはselectorの戻り値の結果が変更される度に rerender されます。 今までのmapStateToPropsのように、Objectを返り値として使用していた場合は、毎回新しいObjectが作成されるため、deepEqualにはなりません。 複数の値を取得する場合の解決策としては3種類あります。 1つ目：useSelectorの第二引数に react-redux が提供している shallowequal を使って、shallowequal の時は Rerender しないようにする。 2つ目: reselect を使って、selector の結果をメモ化することでも rerender を防ぐことができます。 3つ目：必要な値ごとに、useSelector を使って、全て単一の結果を返す。 */}

# useDispatch

`const dispatch = useDispatch();`

{/* つづいて useDispatch について説明します。useDispatch は dispatch です。 action を実行するための dispatch を返します。 */}

---

#### useDispatch

```jsx
import React from "react";
import { useDispatch } from "react-redux";

export const CounterComponent = ({ value }) => {
  const dispatch = useDispatch();

  return (
    <div>
      <span>{value}</span>
      <button onClick={() => dispatch({ type: "increment-counter" })}>
        Increment counter
      </button>
    </div>
  );
};
```

---

#### dispatchを定義して、それを使う

```jsx

```

---

#### dispatch する callback を 子 component にわたす場合

```jsx
import React, { useCallback } from "react";
import { useDispatch } from "react-redux";

export const CounterComponent = ({ value }) => {
  const dispatch = useDispatch();
  const incrementCounter = useCallback(
    () => dispatch({ type: "increment-counter" }),
    [dispatch]
  );

  return (
    <div>
      <span>{value}</span>
      <MyIncrementButton onIncrement={incrementCounter} />
    </div>
  );
};

export const MyIncrementButton = React.memo(({ onIncrement }) => (
  <button onClick={onIncrement}>Increment counter</button>
));
```

#### 複数の値を持ってくるSelectorにしたり

```jsx
import React from "react";
import { useSelector, useDispatch, shallowEqual } from "react-redux";
import { someAction } from "../actions";
import { getTitle } from "../selectors";

const Foo = () => {
  const { title, bar } = useSelector(getTitle, shallowEqual);
  const dispatch = useDispatch();
  const onPressBar = dispatch(someAction);

  return <button onClick={onPressBar}>{title}</button>;
};

export default Foo;
```

{/* state から複数の値を Object として返す Selector にしていったりできます。 先程言ったとおり、複数の値を取ってくる場合は shallowEqual を使いましょう。 reselect を使っている場合は、 selector の方に定義しているので必要無いです。 */}
